# 🧠 智能数据管道 (AI-Driven Smart Pipeline)

## 概述

这是一个**AI驱动的递归知识图谱扩展系统**，它不仅处理单个论文，而且能够智能地识别和递归处理最重要的引用论文，从而构建一个更加完整和有价值的知识图谱。

## 🚀 核心特性

### 1. AI智能引用分析
- 使用 **LangGraph Agents** 分析论文全文，理解上下文
- 基于多个维度评估引用重要性：
  - **基础工作**: 作为理论基础的引用
  - **核心方法**: 算法或方法的关键组成部分
  - **主要对比**: 实验中的基准或最新技术
  - **频率和上下文**: 在关键章节中多次提及

### 2. 递归深度控制
- **默认深度限制**: 1层递归，避免无限扩展
- **可配置**: 通过 CLI 参数或环境变量调整
- **资源保护**: 防止过度的 API 调用和存储消耗

### 3. 智能去重机制
- **存在性检查**: 自动过滤已有完整元数据的论文
- **增量处理**: 只处理新发现的重要引用
- **状态管理**: 追踪处理历史和深度信息

### 4. 时间戳追踪
- **抓取日期**: 记录每篇论文的获取时间
- **批次管理**: 支持按日期筛选和管理论文
- **历史追踪**: 便于后续的增量更新和分析

## 📝 使用方法


## 🔍 工作流程详解

### Phase 1: 论文处理 (标准流程)
1. **PDF下载**: 从 arXiv 获取 PDF 文件
2. **内容提取**: 提取文本和图像内容
3. **AI分析**: 生成摘要、识别领域、提取贡献和方法论
4. **向量化**: 文本和图像嵌入
5. **存储**: 保存到 Neo4j 和 Qdrant

### Phase 2: 智能引用扩展 (新功能)
6. **引用提取**: 从全文中识别 arXiv 引用
7. **AI分析**: 使用 LangGraph Agent 评估引用重要性
8. **智能筛选**: 选择 Top 5-6 最关键的引用
9. **去重过滤**: 排除已有完整元数据的论文
10. **递归处理**: 对新发现的重要引用重复 Phase 1

### Phase 3: 关系构建
11. **图关系**: 创建 `CITES` 关系链接
12. **元数据同步**: 确保所有节点信息完整
13. **质量验证**: 检查处理结果的完整性

## 📊 性能和限制

### 资源控制
- **深度限制**: 默认 1 层，最大推荐 2 层
- **引用数量**: 每层最多 5-6 个重要引用
- **API调用**: 智能批处理，避免过载
- **存储优化**: 增量更新，避免重复处理

### 处理效率
- **并行能力**: 支持多个引用并行处理
- **错误恢复**: 单个引用失败不影响整体流程
- **进度追踪**: 详细的日志记录和状态监控

### 质量保证
- **AI备份**: 多层 fallback 机制
- **数据验证**: 严格的输入输出检查
- **一致性**: 事务性操作确保数据完整性

## 🔧 故障排除

### 常见问题

1. **AI分析失败**
   - 检查 `GROQ_API_KEY` 是否正确设置
   - 确认网络连接和 API 额度

2. **递归深度过深**
   - 检查 `MAX_INGESTION_DEPTH` 设置
   - 监控资源使用情况

3. **数据库连接错误**
   - 确认 Neo4j 和 Qdrant 服务运行正常
   - 检查连接参数和认证信息

### 日志分析
```bash
# 查看详细处理日志

# 监控递归深度

```
